JPC DESIGN — COMPLETE WEBSITE + ADS LANDING PAGE

This package restores the regular JPC Design homepage and adds a separate advertising landing page.

UPLOAD TO GITHUB
1. Unzip this package.
2. Open the JPCDesigns-main folder.
3. In GitHub, open your JPCDesigns repository.
4. Click Add file > Upload files.
5. Select EVERYTHING inside JPCDesigns-main, including the get-started folder.
6. Drag the files into GitHub and allow replacement of existing files.
7. Commit directly to the main branch with: Restore website and add ads landing page
8. Wait for Cloudflare Pages to finish deployment.
